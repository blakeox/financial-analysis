# SEO Implementation Checklist

Use this checklist when creating or updating pages to ensure best SEO practices.

## 📋 Page Creation Checklist

### ✅ Layout & Meta Tags

- [ ] **Title**: 50-60 characters, includes primary keyword and brand
  - Format: `[Primary Keyword] - [Description] | Fanalyx`
  - Example: `Lease Analysis Calculator - Free Tool | Fanalyx`

- [ ] **Description**: 150-160 characters, compelling and keyword-rich
  - Include benefit/value proposition
  - Add call-to-action if appropriate
  - Example: `Free lease vs buy calculator with AI analysis. Compare options instantly.`

- [ ] **Keywords**: 5-10 targeted keywords
  - Primary keyword (most important)
  - 2-3 secondary keywords
  - 2-3 long-tail keywords
  - Related semantic keywords

- [ ] **Type**: Set appropriate content type
  - `website` for homepage/main pages
  - `article` for calculator/tool pages
  - `product` for premium features (future)

- [ ] **Canonical URL**: Verify correct canonical URL
  - Auto-generated by default
  - Override only if needed for duplicates

### ✅ Structured Data

#### Breadcrumbs (Required for all non-homepage pages)
```astro
<StructuredData 
  type="breadcrumb" 
  breadcrumbs={[
    { name: 'Home', url: '/' },
    { name: 'Category', url: '/category' },
    { name: 'Page Name', url: '/page' }
  ]}
/>
```

#### Software Application (Required for calculator pages)
```astro
<StructuredData 
  type="software" 
  softwareApp={{
    name: 'Calculator Name',
    description: 'Full description of what it does',
    category: 'FinanceApplication',
    rating: 4.5,        // Optional but recommended
    ratingCount: 100    // Optional but recommended
  }}
/>
```

#### FAQ Schema (Highly recommended)
```astro
<StructuredData 
  type="faq" 
  faqs={[
    {
      question: 'Question that users commonly ask?',
      answer: 'Clear, comprehensive answer with benefits.'
    },
    // Add 3-5 FAQs minimum
  ]}
/>
```

### ✅ Content Quality

- [ ] **H1 Tag**: One per page, matches or closely related to title
- [ ] **H2-H6 Tags**: Logical hierarchy, descriptive
- [ ] **First Paragraph**: Contains primary keyword naturally
- [ ] **Content Length**: Minimum 300 words of unique content
- [ ] **Internal Links**: Link to 2-3 related pages
- [ ] **External Links**: Link to authoritative sources if applicable
- [ ] **Alt Text**: All images have descriptive alt attributes
- [ ] **Keywords**: Natural integration, no keyword stuffing

### ✅ Technical Requirements

- [ ] **Page Speed**: Loads in under 3 seconds
- [ ] **Mobile Responsive**: Works perfectly on all devices
- [ ] **No Console Errors**: Check browser console
- [ ] **Valid HTML**: No markup errors
- [ ] **Accessibility**: Meets WCAG 2.1 standards
- [ ] **HTTPS**: All resources loaded over HTTPS

## 🔍 Pre-Launch Testing Checklist

### Required Tests

- [ ] **Google Rich Results Test**
  - URL: https://search.google.com/test/rich-results
  - All structured data validates
  - No errors or warnings

- [ ] **Facebook Debugger**
  - URL: https://developers.facebook.com/tools/debug/
  - Image displays correctly
  - Title and description correct

- [ ] **Twitter Card Validator**
  - URL: https://cards-dev.twitter.com/validator
  - Card preview looks good
  - All information correct

- [ ] **Schema Validator**
  - URL: https://validator.schema.org/
  - Paste page HTML
  - No schema errors

- [ ] **Mobile-Friendly Test**
  - URL: https://search.google.com/test/mobile-friendly
  - Page passes mobile test
  - No mobile usability issues

- [ ] **PageSpeed Insights**
  - URL: https://pagespeed.web.dev/
  - Score 90+ on mobile and desktop
  - Core Web Vitals all green

### Browser Testing

- [ ] Chrome (latest)
- [ ] Firefox (latest)
- [ ] Safari (latest)
- [ ] Mobile Safari (iOS)
- [ ] Chrome Mobile (Android)

## 🎯 Common SEO Mistakes to Avoid

### ❌ Don't Do This:
- Keyword stuffing (using keywords unnaturally)
- Duplicate content across pages
- Missing or duplicate meta descriptions
- Broken internal links
- Slow page load times (>3 seconds)
- No mobile optimization
- Missing alt text on images
- Thin content (less than 300 words)
- Using only relative URLs in OG tags
- Forgetting to test structured data

### ✅ Do This Instead:
- Natural keyword integration
- Unique content for each page
- Custom meta descriptions for every page
- Regular link audits
- Optimize for speed (compress images, lazy load)
- Mobile-first design
- Descriptive alt text on all images
- Comprehensive, valuable content
- Absolute URLs for all social sharing
- Test everything before launch

## 🚀 Quick Reference

### Title Formula
```
[Primary Keyword] - [Benefit/Feature] | Fanalyx
```

### Description Formula
```
Free [primary keyword] with [key feature]. [Benefit statement]. [Call-to-action or additional benefit].
```

### Keyword Strategy
1. **Primary** (1): Most important, in title and first paragraph
2. **Secondary** (2-3): In H2 tags and throughout content
3. **Long-tail** (2-3): In FAQs and detailed content
4. **LSI/Related** (3-5): Natural throughout content

### FAQ Strategy
- **Question 1**: What is [topic]? (Definition)
- **Question 2**: How does [tool] work? (Process)
- **Question 3**: What do I need? (Requirements)
- **Question 4**: Is it free? (Pricing)
- **Question 5**: Can I [use case]? (Capabilities)
